# Workora Legal-Safe Elite Website

Next.js App Router site for Workora workforce infrastructure.

## Includes
- Conversion-first homepage
- 12 SEO landing pages
- English, Spanish, French, German and Russian route support
- Advanced EU payroll/tax calculator page
- Compliance-first legal positioning
- Organization, FAQ and Breadcrumb JSON-LD
- Sitemap, robots, OpenGraph and favicon/logo assets

## Run locally
```bash
npm install
npm run dev
```

## Deploy on Vercel
1. Upload/push this repository to GitHub.
2. Import the GitHub repo into Vercel.
3. Deploy.
4. Add your domain in Vercel > Project > Domains.

## Important
This website copy is built to reduce risky employment-wrapper optics, but it is not legal advice. Review with EU labor, tax, immigration, payroll and GDPR counsel before paid advertising or high-scale launch.
